# EdgePilotAI Live for OpenAI and Codex

EdgePilotAI Live extends the EdgePilotAI workflow from strategy research into locally controlled paper, exchange demo, and live operation in supported OpenAI and Codex workspaces.

**EdgePilotAI Live is currently invite-only.**

## What Live supports

- strategy discovery and configuration;
- historical backtests before deployment;
- local paper, exchange demo, and live workflows;
- local credential handling;
- active-session monitoring and stop controls.

## Safety boundary

Trading credentials are entered and stored locally and are not sent to the AI model. Never paste credentials into an ordinary chat, support message, or public form.

A Demo or Live session should begin only after the user confirms the venue, mode, capital, position sizing, risk settings, and stop conditions. The user can monitor and stop an active session.
